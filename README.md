# Ventas-Guate
Webhooks para whatsapp business api

## SEO (claude-seo)

Plugin [claude-seo](https://github.com/AgriciDaniel/claude-seo) habilitado a nivel de proyecto en `.claude/settings.json`. Al abrir Claude Code en este repo se ofrece instalarlo automáticamente.

| Comando | Uso |
|---|---|
| `/seo setup` | Prepara navegador headless (Playwright) |
| `/seo audit https://www.ventasguate.gt` | Auditoría completa |
| `/seo ecommerce https://www.ventasguate.gt` | SEO de productos / Google Shopping |
| `/seo local https://www.ventasguate.gt` | Google Business Profile / map pack |
| `/seo geo https://www.ventasguate.gt` | Visibilidad en AI Overviews, ChatGPT, Perplexity |
| `/seo schema https://www.ventasguate.gt` | Validar / generar Schema.org |
| `/seo page <url>` | Análisis de una página |

Instalación manual: `/plugin marketplace add AgriciDaniel/claude-seo` → `/plugin install claude-seo@agricidaniel-claude-seo`.
